# Palette source attribution

Imported palette data belongs to its upstream authors. Exact revisions and files
are available through each palette registration and in the fixture manifest.
Snapshots are used for offline verification; builds never fetch these sources.

`PaletteSource::licence` records an upstream licence identifier or descriptive
name at the pinned revision. `None` means the licence has not been verified;
it does not imply permission to use the source. Base16, Oceanic Next and Panda
currently have unverified licences. The labels describe upstream notices and
do not assess compatibility with Ferriswatch's licence.

Most labels come from the snapshots linked below. Gruvbox declares MIT/X11 in
its [pinned README](https://github.com/morhetz/gruvbox/blob/5d15b2765f59754d7ac263c88a0f6e3e58124951/README.md#license).
Material's notice is labelled `GNU GPL version 2` without inferring an
only/or-later choice. JetBrains retains the name of its build terms.
